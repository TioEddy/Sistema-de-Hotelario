# Sistema de Gestão Hoteleira 🤓

O Sistema de Gestão Hoteleira é uma aplicação web completa desenvolvida como projeto final da disciplina de Programação Avançada em Java. O sistema foi concebido para otimizar e automatizar os processos operacionais de um hotel, oferecendo uma plataforma integrada para gestão de reservas, check-in/check-out, controle financeiro, administração de quartos e muito mais.

O projeto foi desenvolvido como trabalho em grupo, aplicando os conceitos avançados de programação Java, arquitetura MVC, padrões de projeto e boas práticas de desenvolvimento.
